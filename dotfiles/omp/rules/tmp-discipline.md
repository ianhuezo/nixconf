# Throwaway work goes to /tmp

- Any exploratory, experimental, scratch, or throwaway work that is not part of the deliverable MUST be created under /tmp (e.g. a per-task temp dir), never inside the repository or home directory.
- If the work must be kept, move it into the workspace; /tmp is ephemeral.
